# Code of Conduct

Sparky follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep feedback about the work, not the person. Harassment of any kind isn't tolerated.

Report problems to the maintainer through a private GitHub message to [@slahiri](https://github.com/slahiri). Reports are kept confidential.
